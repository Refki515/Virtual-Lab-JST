========================================
VIRTUAL LAB JST - UNIVERSAL DATASET
Supervised Learning dengan Upload CSV
========================================

CARA PAKAI:
-----------

1. BUKA FILE
   - Double-click: index.html
   - Atau drag ke browser

2. UPLOAD DATASET
   - Klik area upload atau drag CSV
   - Format: baris 1 = header (nama kolom), baris selanjutnya = data
   - Contoh sudah ada: sample_dataset.csv
   
   Setelah upload:
   ✓ Target kolom otomatis terpilih (kolom binary terakhir)
   ✓ Semua fitur otomatis tercentang
   ✓ Model siap training (sudah auto-reset)
   ✓ Info dataset muncul di atas

3. TRAINING
   - Klik "Auto Run" untuk training otomatis sampai selesai
   - Atau "Fast Train" untuk training cepat
   - Lihat grafik error turun, epoch bertambah
   - Status berubah: Siap → Training... → Selesai

4. PREDIKSI
   - Setelah training selesai, isi nilai fitur di panel "Uji Model"
   - Klik "Prediksi Sekarang"
   - Hasil: Positif/Negatif dengan skor confidence

5. DOWNLOAD MODEL
   - Klik "Download Model (JSON)"
   - File berisi weights, bias, normalisasi, encoder

ALGORITMA:
----------
- Perceptron: step function, cocok klasifikasi binary sederhana
- Hebb Rule: pembelajaran asosiatif
- Delta Rule (LMS): gradient descent, linear output
- Backpropagation: multi-layer, paling akurat

PARAMETER:
----------
- Learning Rate: 0.01-0.5 (kecil=lambat tapi stabil)
- Max Epoch: 200-500 (iterasi training)
- Threshold: 0.5 (batas keputusan output)
- Hidden Layer: 5-20 (untuk Backpropagation saja)

VERIFIKASI SETELAH UPLOAD:
---------------------------
✓ Info dataset muncul (jumlah records & kolom)
✓ Log console tampil: "Dataset terverifikasi..."
✓ Target dropdown sudah terisi
✓ Fitur checkbox sudah tercentang
✓ Tombol "Auto Run" aktif (tidak disabled)
✓ Stats menunjukkan "Siap"

TROUBLESHOOTING:
----------------
Q: Setelah upload, tombol masih disabled?
A: Refresh browser, pastikan minimal 2 baris data (header + 1 data)

Q: Training tidak jalan?
A: Cek console log, pastikan target & fitur sudah terpilih

Q: Error tidak turun?
A: Turunkan learning rate, atau ganti algoritma ke Backpropagation

Q: Prediksi salah?
A: Training belum convergence, tambah epoch atau ubah learning rate
