Algoritma: Perceptron, Hebb Rule, Delta Rule, Backpropagation

Panduan Penggunaan

Langkah 1: Upload Dataset

Klik area upload atau drag file CSV. Format: baris pertama = header (nama kolom), baris berikutnya = data.

age,gender,heart_attack
45,M,1

Langkah 2: Pilih Target & Fitur

Target = kolom yang ingin diprediksi (output). Fitur = kolom yang digunakan untuk memprediksi (input).

Pilih minimal 2 fitur agar model dapat belajar pola.

Langkah 3: Pilih Algoritma

Perceptron: Cocok untuk klasifikasi binary sederhana.

Hebb Rule: Pembelajaran asosiatif, cocok untuk pola bipolar.

Delta Rule (LMS): Minimasi error dengan gradient descent.

Backpropagation: Multi-layer, paling akurat untuk dataset kompleks.

Langkah 4: Atur Parameter

Learning Rate (α): 0.01-0.5 (kecil = lambat, besar = cepat tapi bisa unstable)

Max Epoch: 200-500 (iterasi training)

Threshold: 0.5 (batas keputusan untuk output)

Langkah 5: Training

Klik Auto Run untuk training otomatis, atau Fast Train setelah Reset.

Lihat grafik error — harus turun seiring epoch bertambah.

Langkah 6: Prediksi

Setelah training selesai, isi input fitur baru di panel "Uji Model", lalu klik "Prediksi Sekarang".

Download Model

Klik tombol "Download Model" untuk menyimpan weights, bias, dan konfigurasi sebagai JSON.
